# 手机号白名单与移除后的任务取消

Status: superseded by ADR0008（用户撤回业务绑定；未实施） · Date: 2026-11-04

最新指令明确：白名单暂不接入实际业务，其作用不是控制谁能使用公司Agent。下文为已经撤回的历史解释，不能作为准入拦截、任务取消或实施依据；以[ADR0008](0008-standalone-phone-list.md)为准。

用户明确要求的是账号白名单，不是新的用户认证。管理员直接登记手机号，后端与已有当前用户信息中的`mobileNumber`匹配，姓名不参与；不新增认证、Token核验、任意账号目录或“先登录后添加”的前置，也不取消原有登录与设备授权。

用户选择移除名单时同时取消未执行部分，而不是只禁止新请求或暂停保留：该账号后续新发起的公司Agent请求不再获准，尚未开始的公司Agent任务、任务后续未执行阶段和周期计划后续执行均取消。已经下发的设备指令不强行打断、不回滚已发生操作，历史及执行结果保留；办公室及小程序其他业务不在本轮扩大控制。

取消不是暂停：重新加入名单只恢复以后使用公司Agent的资格，不自动复活已取消任务或计划，不补跑取消期间的执行；需要再次执行时按原有任务提案与人工确认流程重新创建。此选择避免加回名单后旧任务意外重新执行，但意味着不能靠恢复白名单撤销任务取消结果。

此决策记录用户在“仅按手机号匹配”“移除还限制未执行任务”“取消而非暂停”三项选择中的明确答案，不表示功能已经交付或授权立即在真实业务启用。实施与验收入口：[白名单票据](../../.scratch/admin-console-governance/issues/02-user-allowlist.md)、[范围纠正及历史证据](../../.scratch/admin-console-governance/account-admission-research.md)。
