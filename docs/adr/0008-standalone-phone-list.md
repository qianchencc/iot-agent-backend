# 手机号白名单独立维护，不接入业务

Status: accepted · Date: 2026-11-04 · Supersedes: ADR0007

用户明确纠正：白名单暂时不接入实际业务，其作用也不是控制谁能使用公司Agent。本轮仅提供管理员维护手机号与可选姓名备注的持久化名单，添加、移除、空名单及名单故障均不影响公司或办公室Agent、原有身份认证、设备权限、任务及周期计划；不实现准入匹配或任务取消，不新增官方账号目录或要求用户先登录。

名单维护与成员业务轨迹是两件事。审计成员来自已有可信业务身份和业务事件，不以白名单作为成员目录或读取前置，不把名单备注说成官方姓名。名单管理操作可以记录管理员变更事件，但不能制造“已开通Agent权限”“已取消任务”等假结果。

这一决定撤回ADR0007的业务绑定，不对名单未来用途作推断。用户已同意其余控制台范围并要求继续实施：独立管理员登录、真实运行配置管理、按用户组织的公司／办公室操作审计；范围与验证入口见[规格](../../.scratch/admin-console-governance/spec.md)。
