# 同步与存储治理

处理本目录工作先读 `README.md` 的票据与依赖，再读 `spec.md` 的用户最新决定；实施前快照在 `evidence.md`，实际实施／运行证据在 `verification.json`，不把历史测量当实时状态。
用户已明确上游副本可重建，不为其增加时间点恢复、备份链或复杂迁移；本轮获准范围是票据内的日志退出与局部减写，保留本地读取、授权和发布正确性。任务等本地记录及无关旧库不在清理范围。
沿用仓根本地读取与共享事实规则，代码修改由主代理负责；调查子代理只读，验证不用客户上游。
实现、隔离MySQL验证、部署和真实业务验收分别记录；维护方案时同步更新执行状态，不复制完整业务契约。
