## 存储与策略的预期变化

- **主要空间收益来自01。** 按旧快照20.80GB减19.37GB，业务卷约1.43GB量级；这只是静态估算，执行前后重新测量，不承诺固定大小。
- **仅关闭不清理，不会立即释放旧日志。** 不能把日志搬到新归档后宣称释放空间；工作目录内旧归档另列结果，不重复计算。
- **02—04主要减少持续操作成本。** 关闭binlog后SQL、索引和事务成本仍存在，所以做简单差量；不承诺现有表文件随之缩小。
- **保留必要存储。** 事实、索引、暂存、进度和正常数据库内部恢复文件仍会增长；不为零写引入保护新表，不取消完整暂存和失败原子性。
- **不保留假想恢复要求。** binlog只按真实复制／订阅用途检查，不要求为上游副本设计RPO／RTO或备份项目；部署前仍要核对实例归属和实际在途业务。
