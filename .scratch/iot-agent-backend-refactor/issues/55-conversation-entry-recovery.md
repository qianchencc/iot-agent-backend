# 55：会话进入与恢复不得拖住已有业务视图

Status: ready-for-human
Blocked by: none

## 目标与边界

- 用户认可修复：会话恢复重复全量读取、前端重开先显示已有对话、身份缓存重启恢复、入口分段测时。
- backend固定基线db8e58b，mp固定基线2445bfa。现有其它工作区改动保留；不启动子代理；真实页面验收由用户完成，不执行控制、创建任务或发送通知。
- 不是取消认证，不信任客户端身份声明；持久身份仅复用同网关、同租户、同凭据已验证结果，受原有效期和持久失效屏障约束。存储失败退回真实核验，不放宽授权。
- 前端旧会话仅作展示；发送、确认、选择写入、清除等变更必须等待本次后端对齐，拒绝访问、切换身份及清除后不得恢复旧内容。

## 已证实

- ConversationFacade.current逐轮调用events.read(id)，JdbcConversationStore每次SELECT整个会话事件。真实5轮232事件累计读1160行；2轮122事件读244行。
- 本地身份首次请求实际返回ACCOUNT_IDENTITY_PREPARING，随后正常。缓存仅进程内；前端把这段等待也显示为恢复对话。
- 当前抽样历史恢复16–83ms，不能证明用户十几秒的主要耗时在SQL。页面渲染仍需用户确认，不把空会话或接口耗时代替前端证据。

## 验收

- [x] 多轮恢复一次读取事件，保持每轮事件顺序与完整内容；空会话不读事件。
- [x] 后端重启能复用有效已验证身份；跨身份/网关/租户隔离，过期或拒绝后旧身份不能复活，Redis/屏障故障不放行未知身份。
- [x] 同身份重开先显示已有对话，本次后端返回前变更操作不可用；迟到响应和清除不会回填旧会话。组件烟测通过，非页面验收。
- [x] 入口测时仅包含阶段和数值，不记录凭据、对话内容或设备数据。
- [x] 回归、实际只读恢复、重启及开发编译完成。
- [ ] 用户在实际开发者工具确认进入、预览及继续操作的体验。

## 回归边界

复用公开ConversationFacade.current、AccountPrincipalVerifier.gateway以及前端会话恢复生命周期；不测私有函数或源码文本，不为原错误查询次数重钉断言。

证据：[会话进入与恢复改进](../evidence/conversation-entry-recovery-2026-11-02.md)。
