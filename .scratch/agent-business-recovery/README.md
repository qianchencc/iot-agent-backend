## 缓存支线的集成门禁

外部缓存工作区的47（普通查询/身份准备）、48（能耗流完整性）、49（前端准备落位）、50（真实读取验收）继续有效。它们当前未作为提交进入本分支；本执行入口不建立不存在的本地票据链接，也不声称缓存已通过。

集成时记录明确来源提交及范围，保留当前已有成果，不把业务重构反向同步到Runtime。缓存分支自身保留准备态、当前/历史、完整30天/同比环比、刷新和隔离的工程检查；本轮集成后复验所选受影响代表路径，不额外要求全量前端通过。Agent工具不能把preparing当无设备或无能耗。16关闭前须有缓存可审查提交、安全集成和代表页面证据；此前可独立推进不依赖未提交缓存实现的业务票。
