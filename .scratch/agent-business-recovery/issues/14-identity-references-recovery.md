# 14: 身份、业务引用与会话恢复

**What to build:** 全链路保持真实 principal、source、tenant：Office 与 Company 的设备、事实、历史、任务与报告严格隔离；会话可解析所有引用类型（告警事件、环境/设备、报表、任务、周期计划），结合当前时间与已解析提案上下文；失败时保留原始范围、时间与动作，不静默换成“当前”或空上下文；断线重连可恢复/重放/取消且不产生重复业务事实；授权账号切换在独立隔离实例/登录中验证，不清除当前登录、不伪造凭证。身份与隔离不变量必须由各业务域自身实现，本票只负责跨域引用解析与恢复集成，不把不变量推迟到本票。

**Blocked by:** [01: Java 业务定义与通用 Node 执行引擎](01-java-business-generic-engine.md)

**Status:** ready-for-agent

## 本票必须自包含的规则

- principal、tenant、source 在 Java 入口一次性核验并在整个业务链路传递；Node、模型、客户端文本不得改写或补造身份。
- Office 与 Company 的来源隔离覆盖设备目录、草案、任务、报告、告警、通知与历史；同一 tenant 下不同用户之间同样隔离。
- 引用类型至少覆盖：告警事件（含原始时间窗）、环境/设备、报表、任务、周期计划。引用必须解析到真实业务事实；无法解析时明确错误，不按标题猜测或伪造来源。
- “当前时间”与相对时间（今天、明天、昨天、最近一周）在解析时固化为绝对时间与区域，并在提案/确认单中可见；后续上下文变化不改写已固化的原始时间。
- 失败（上游错误、权限变化、引用失效、超时）时保留原 scope/时间/动作，显示可恢复错误；不得用当前授权或当前时间静默替换原请求。
- 断线重连/rejoin：恢复会话、重放未完成事件、允许取消待确认提案；不重复创建草案、任务、报告或通知。事件顺序与幂等键需可核对。
- 账号切换验收必须在独立隔离实例与独立登录中进行，不清理现有登录、不复用当前用户凭证；切换后对话、设备、任务、未读通知按新身份重新加载且不串数据。
- 领域不变量（授权裁剪、任务不可变、通知已读、报表归属等）由各自票据域内实现；本票只做跨域引用解析与恢复集成，不以“14 会兜底”为由跳过域内校验。
- 跨域集成可在后续票据完成后收口，但本票不得以假来源、假历史或前端本地伪造上下文通过。
- 本票不写生产数据、不创建任务、不发送通知、不执行控制。

## 验收条件

- [ ] 真实 Office 账号：设备查询、草案、历史只显示 Office 关注区域授权范围；同一会话切到 Company 来源后只显示 Company 范围，双方数据不串。
- [ ] 同一 tenant 下用另一真实授权账号（独立隔离登录）验证设备、任务、通知、报告隔离；当前登录不被清除，凭证不出现在日志/截图。
- [ ] 依次引用告警事件、设备、报表、任务、周期计划，均解析到真实事实，回复可指出对象与原时间；不存在的引用明确报错。
- [ ] 相对时间“明天 18:00”“最近一周”在提案中显示为固化绝对时间与 Asia/Shanghai 区域；等待或跨天后上下文不被改写。
- [ ] 构造上游失败/权限撤销/引用失效/确认超时，前端保留原范围、原时间与原动作并提示可恢复错误，不替换为当前范围或“无结果”。
- [ ] 确认过程中断线并重连，可恢复或取消原提案；重放后不产生重复草案/任务/通知，事件顺序与幂等键可核对。
- [ ] 独立实例完成账号切换，切换后对话、设备、任务、未读通知按新身份加载；旧身份数据不可见、不可引用。
- [ ] 越权构造 principal/source/tenant 篡改时被拒绝；领域内授权校验在本域生效，而非仅靠跨域收口。
- [ ] 全程无生产写入、无任务、无通知、无控制；证据含截图、脱敏诊断、独立实例标识、构建/账号/来源/区域。

## 可追溯 Runtime 业务参考职责

对照 Runtime 的身份解析、source 隔离、时间/引用上下文、断线恢复与账号切换行为，记录“Runtime 行为 → Java 校验/引用/恢复 → 前端证据”。Runtime 只读，不修改、不切换生产；不以修改 Runtime 迁就新后端。

## 工程回归与真实前端验收的区别

工程回归可验证身份传递、引用解析、幂等与领域校验；业务完成必须由真实前端在两种来源、两个账号、断线重连场景中观察到隔离与恢复，不以 token 注入或接口单测替代。

## 隔离与安全约束

业务修改只在隔离 worktree；原 backend 与 Runtime 只读，必要的真实前端修复另用独立 mp worktree且保持原契约。第二身份使用独立隔离实例/登录，不注销当前账号、不伪造凭证、不复制生产会话。不写生产数据、不发送生产通知、不执行控制。

## 证据要求

证据落在 `.scratch/agent-business-recovery/evidence/<CASE-ID>/`，覆盖 `ID-01`、`ID-02`、`ID-03` 及验收矩阵中的引用/恢复案例；含两种来源、两个账号、断线重连、失败保留与引用解析截图，脱敏诊断、构建/账号/来源/区域。任何凭证、token、手机号需脱敏。

## 本票尚未验收

本票仅发布规格，尚未执行任何验收；不得以登录成功、接口 401/403 或单测通过宣称身份隔离与恢复业务完成。
