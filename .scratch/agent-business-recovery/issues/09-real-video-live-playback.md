# 09: 真实视频直播与回放

**What to build:** 公司 Agent 的监控视频能力在真实授权账号下可用：从对话、设备页或告警台账进入摄像头，直播卡片展示来自真实摄像头的画面，且画面随时间实际变化；回放卡片提供起止时间与时区表单，按真实录像源播放，范围校验失败时明确拒绝；网络中断可重连，离开/关闭卡片释放播放资源与凭证；短时播放地址不持久化、不泄露到日志或前端可复用存储。告警关联候选与原始事件窗口复用 [08](08-safety-ledger-event-reference.md) 的能力。样例视频、静态首帧或伪造流不能作为业务通过证据。

**Blocked by:** [01: Java业务定义与通用执行](01-java-business-generic-engine.md)；[08: 安全台账与关联候选](08-safety-ledger-event-reference.md)

可先调查播放器与直接设备入口，但本票闭票必须在08完成后，于同一集成构建完成告警关联入口的真实播放。`COMP-SAFE-02/07/08`整条CASE由本票收口，08保留候选/卡片贡献证据，不以尚缺播放阻塞08闭票。

## 本票必须自包含的规则

- 摄像头候选只来自当前授权范围与当前来源（Office/Company），从对话、设备页、告警台账进入时使用同一授权事实。
- 直播必须展示真实摄像头的连续画面；验收要求观察到画面随时间变化（两个不同时刻的截图，或一段真实录制），单张截图不足以证明直播。
- 摄像头离线、状态未知、无权限时如实显示对应状态，不展示旧画面或“假在线”。
- 回放必须带起止时间与时区，服务端校验时间窗与允许保留期；越界请求明确拒绝，不静默截断或回落到直播。既有验收案例采用超过三天拒绝的口径；实施时以 Runtime/产品合同核对，但不得放宽为静默忽略。
- 播放地址为短时凭证，不写入持久业务事实、不进入普通日志、不在前端长期保存；关闭/离开卡片必须释放流与凭证。
- 网络中断后允许重连并恢复播放；重连不得产生重复计费/重复播放会话或权限提升；无法恢复时明确报错。
- 告警进入路径复用 [08](08-safety-ledger-event-reference.md) 的候选与事件前后 ±15 分钟窗口，不另造一套时间。
- 视频数据只读；本票不执行设备控制、不创建任务、不发送通知。
- 样例视频、录屏素材或伪造流仅可用于工程回归，不能当作真实摄像头业务验收。

## 验收条件

- [ ] 真实授权账号在前端输入“看看大堂摄像头”（或其他真实摄像头），直播卡片打开并出现真实画面；两个不同时刻的截图或一段真实录制证明画面在变化。
- [ ] 从设备页/告警台账进入同一摄像头，授权范围一致；无权限或离线摄像头显示真实状态，不显示旧画面或假在线。
- [ ] 输入“回放昨天下午两点前后 26 楼运营办公区的录像”，前端提供起止时间与时区表单，按真实录像源播放；两个不同时刻的画面证明回放在推进。
- [ ] 起止时间越界（如超过允许保留期，既有案例为 3 天）时明确拒绝并提示，不播放替代内容或静默截断。
- [ ] 播放中关闭卡片/离开页面后，流与短时凭证释放；再次进入需要重新获取播放授权。
- [ ] 断网或中断后重连可恢复播放；无法恢复时显示明确错误；重连过程无重复会话或权限扩大。
- [ ] 告警详情进入回放时使用原事件前后 15 分钟窗口，不替换为当前时间。
- [ ] 全程无生产写入、无任务、无通知、无设备控制；证据含真实画面截图/录制、脱敏诊断、构建/账号/来源/区域，且无凭证泄露。

## 工程回归与真实前端验收的区别

工程回归可用受控视频源证明接口与释放逻辑；业务完成必须由真实摄像头画面变化与真实录像推进证明，不能以接口返回地址、卡片出现或样例视频替代。

## 隔离与安全约束

业务修改只在隔离 worktree；原 backend 与 Runtime 只读，必要的真实前端修复另用独立 mp worktree且保持原契约。只读真实视频源，允许授权取流所需请求；不触达设备控制或生产业务写入，不创建任务或通知；播放凭证按短时敏感信息处理。
