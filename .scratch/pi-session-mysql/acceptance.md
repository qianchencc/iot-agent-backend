## 预期效果不是保证

- 新 Node 可替换，不等于正在进行的模型请求能无缝续跑；默认中断说明后继续新一轮。
- MySQL 不自动消除并发写入或不确定提交；必须有 S03–S05 证据。
- Pi 一致性测试不替代 U01–U06；这些迁移样本可纳入原业务恢复约20条代表路径，不另要求20条重复样本。
- 未选中全说明书案例保持未验收；已发现的旧业务缺陷公开挂阻塞，不能以“存储已换”掩盖。
