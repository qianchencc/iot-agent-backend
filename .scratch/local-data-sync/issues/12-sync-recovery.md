# 12: 跨领域连续同步/历史校正/断点幂等/凭据轮换/停机恢复与只读运维证据

**What to build:** 在02真实目录同步闭环上验证跨领域持续采集、深夜校正、幂等断点、凭据失效暂停/合法轮换恢复与受控诊断。工作由持久登记和当前合法授权共同决定，不随缓存30分钟闲置、Redis清空或页面关闭消失；本票不是给前票补一个此前无法运行的调度框架。

**Blocked by:** [04-state-drafts.md](04-state-drafts.md)、[05-energy-history.md](05-energy-history.md)、[06-environment-history.md](06-environment-history.md)、[07-safety-ledger.md](07-safety-ledger.md)；未完成不得开工。

**Status:** ready-for-agent
**Type:** implementation
**契约参照:** [../spec.md](../spec.md) · [../acceptance.md](../acceptance.md)

## 范围
- 连续调度：当前约 60 秒、上海深夜历史/低频、按需补缺统一登记去重（按数据类别和真实授权范围合并工作，不按统计问法造扫描）；同范围 singleflight 沿用；受限并发沿用现有上限（能耗 6），不新建队列/调度平台/线程池扩张。
- 历史校正按G3首次及每天夜里全量执行，范围为合法来源可访问历史，无24个月边界；用户说明最多十来分钟，不新增限时运行窗口或跨夜轮转。初始补采/当前续采/历史校正使用既有受限并发，不无限抢占；本轮不新增自动删除，不承诺法定永久保留。
- 断点幂等：去重唯一键按 G2 核实的来源记录 ID 或组合键，不预设 timestamp+quality 之类的臆测组合；页号漂移、上游日期过滤不可靠按 01 核实口径以窗口重扫为准备；重复采集不重复计数、不重复发布；批写成功才推进进度/覆盖；部分页失败保留上次完整。
- 凭据面：同步凭据失效或明确拒绝→暂停对应范围并停止对外供数（不返旧值），与普通网络失败保留旧值分开；上游 token 更换下稳定主体不变，采集工作按登记主体接管；任务托管凭据 resume 重绑既有机制保持；加密根轮换只按已核实存在的机制记录边界，不宣称统一轮换系统、不新造服务账号。
- 停机恢复：正常与非正常重启后按持久进度续跑；错过深夜启动时间后恢复补跑且同范围不重入；无无限积压、不重发真实动作。
- 故障隔离：MySQL不可用时不推进持久进度，使用既有脱敏运行诊断说明失败，不能声称已写入不可用的数据库；恢复后续跑。Redis故障不丢登记/数据，也不能取消同范围单飞与授权检查；不影响既有业务事实事务。
- 只读运维证据：每范围/类别的进度、覆盖、最近成功/尝试时间、失败摘要的只读视图，复用既有受控诊断/管理端只读能力；不新增通用管理台、不暴露任意 SQL/表浏览；healthz 语义不扩张。

## 非目标
- 不重做各领域读取与消费（02—11）；不做清理与出口约束（13）；不做发布验收（14）；不改凭据加密存储格式与安全根治理。

## 行为验收
- [ ] 登记范围闲置超 30 分钟、页面关闭、Redis 清空后同步仍按登记继续；缓存条目淘汰不删除登记/进度（E09）。
- [ ] 午夜停机恢复补跑到期工作，同范围不重入、不重复计数（E10/E06）。
- [ ] 中断批次重放幂等：无重复样本/事件/目录版本，进度不超前于已提交数据（E06/E07）。
- [ ] 凭据失效/明确拒绝：对应范围暂停且可观测、读取不返旧值；恢复重核后续跑；无跨主体借用凭据（E11/E14）。
- [ ] 初始补采与深夜校正并行不互相饿死；并发不超既有上限。
- [ ] MySQL故障期间无伪成功进度，恢复后依据最后提交点续跑；允许重读核验失败边界，不重复累计；当日到期全量与故障恢复分开，不因每个普通查询或重复恢复信号另起全量。
- [ ] 运维只读视图可区分采样时间/成功同步时间/尝试时间与失败摘要，仅授权访问。
- [ ] 以隔离程序实际运行上述故障/重启场景，记录版本、配置、数据范围、阻断对象、结果、出口计数与时间；不能仅用内存测试声称持久恢复。

## 证据与既有公开接口
- 公开符号：SchemaMigrations、ReadSnapshots（create/read/load/refreshActive/revoke/admit）、既有 Redis 协调存储的锁与幂等标记能力、IotAdapterFactory/ObservationAdapterFactory（同步采集出口装配）。
- 既有测试接口：ReadSnapshotsTest（闲置/恢复/代际语义参考）、SchemaMigrationsUpgradeBehaviorTest（升级幂等）、TaskLifecycleRecoveryContractTest（恢复模式参考）；测试经包根入口断言，不从 internal 导入，不开新测试框架。
