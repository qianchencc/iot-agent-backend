# 13: 全普通入口干净切换与客户数据出口约束

**What to build:** 完成全局切换证明：每个普通入口都能从本地数据工作，只有同步、身份核验、真实控制/执行回读和视频开流持有必要外部能力。删除已失去用途的回源loader和临时包装，不保留“本地失败再访问上游”的成功兜底；以后新增普通接口也不能绕开约束。

**Blocked by:** [11-unified-consumers.md](11-unified-consumers.md)、[12-sync-recovery.md](12-sync-recovery.md)；两者完成后才开始全局收口。
**Status:** ready-for-agent
**Type:** implementation
**契约参照:** [完整规格](../spec.md) · [验收矩阵](../acceptance.md)

## 范围与分类

- 建立完整调用路径清单：HTTP→包根入口→本地实现，Agent前置/工具/引用→同一业务入口，任务准备/只读阶段、报告取证和下载、组合观察能力分别列出。不能仅列ObservationOperationEnum就声称覆盖所有能力。
- 重点核查参数旁路：tools直接调用、candidateSets绑定状态、capabilities、Office与Company分支、安全/视频/能耗授权scope、普通显示名、region seen前置、dashboard分段原始分页、检查点桥的报告取证。
- 按业务语义分类而非HTTP动词：POST/down中可能是状态查询，GET也可能创建短期流；前者仍归同步/本地读，不能因为POST就归真实控制。
- 混合网关按操作拆职责，不按整类划例外：TaskControlPreflight等提案准备本地化，执行前即时复核与dispatch/readback保留专门出口；候选集事实读取不误判为回源。
- 模型提供商、Agent Engine桥、Pi Session接口、管理端监督调用不是客户IoT采集，不纳入“全部外部HTTP为零”的错误目标。

## 干净切换

- 前票已经逐领域迁完消费者，本票检查所有普通ReadSnapshots loader、组合层嵌套loader及透传包装，不允许一层缓存掩盖底层回源。
- 移除确已无消费者的旧回源实现、专门Agent缓存包装、重复内存原始历史缓存、旧预热和配置项；先查引用，不能仅凭类名删除仍用于合法同步/执行的适配器或有效本地缓存。
- 报告下载仅从原有本地报告事实渲染；若遗留远程REPORT_DOWNLOAD入口可达，迁移其调用者并移除过时远程分支，不能保留未配置代理作为未来回源兜底，也不能删除公开下载能力。
- 原始上游分页适配在同步中仍需要时保留，只收回业务读取调用权；缓存恢复屏障不冒充同步断点，旧报告/任务/候选事实不迁为缓存。
- 复用既有ArchUnit与进程内网关fixture表达边界，公开测试面不访问internal；网络出口实际计数验证优先于源码字串检查。不新增测试框架或通用拦截平台。
- 更新配置/启动说明和业务入口文档；旧历史证据保留但明确版本及适用范围，不把新规划反写成旧验收已通过。

## 验收

- [ ] 每个公开普通入口有对应本地来源、消费者、测试/烟测证据和负责领域，无未分类调用；新增或遗漏路径回填总验收矩阵。
- [ ] 有效身份/授权与已覆盖数据条件下，隔离程序阻断客户数据采集出口后，全部普通读取成功且网络计数0。
- [ ] Redis空/不可用仍从MySQL服务；MySQL/授权持久校验失败不回源兜底，未覆盖不伪空。
- [ ] 只改变工具参数形状、HTTP入口或Agent入口不能绕过本地数据路径。
- [ ] 明确身份核验、同步、控制前复核、下发、回读和开流的允许调用清单；隔离fixture证明它们仍可工作且不被普通读取误用。
- [ ] 混合任务网关与检查点桥逐操作验证：只读无回源，真实动作仍保留权威复核；Node不持有数据库/同步凭据或业务缓存。
- [ ] 同租户不同主体、不同来源及旧凭据缓存均不能绕过当前可见性；删除缓存包装没有移除原有安全检查。
- [ ] obsolete代码、配置和注释无残留引用，无永久双读/双写成功兜底；必要同步原始适配未被误删。
- [ ] 既有公开契约保持，数据质量/时间、候选句柄、报告下载、任务与NDJSON终态无能力缩水。
- [ ] 交付边界审查依据固定变更基点，检查规格与工程规范两轴；受影响检查和整体回归实际运行，失败分类披露，不用旧基线结果冒充当前构建。

## 证据边界

使用独立端口、schema、Redis与会话状态，进程内网关fixture不控制真实设备。运行最终候选程序并观察出口计数、结果及状态；测试通过不能代替烟测，更不能代替14的真实微信截图。禁止生产控制/任务/通知/配置写入，不重启其他工作区服务。

## 非目标

不重做业务规则、模型路由、Pi会话或统计算法，不修复与本切换无关的视频窗口/错误文案问题。发现无关问题如实记录影响；若妨碍本轮已承诺行为，修复后再通过验收，不能靠缩小覆盖绕过。
