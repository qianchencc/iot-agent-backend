# OFFICE-DIRECTORY-PAGE-01：Office 任务持续加载

## 根因与范围

Office 照明关联目录默认分页顺序不稳定：总数 159，两个分页分别返回 100／59 条，但跨页重复 12 条，实际仅 147 条不同记录。严格完整性检查拒收目录；此前没有成功批次，所以任务时间轴和日历返回 `503 TASK_READ_PREPARING`，真实小程序持续显示任务加载中。

只在 `IotGatewayRoutes.runtimeOfficeSources` 的 `office-association.lighting` 请求参数增加 `sort=id,asc`。真实只读探测得到 159 条不同记录、跨页重复为 0。保留重复／完整性检查、授权范围过滤和来源隔离；不把失败当作空任务。

不改前端组件、额外提示、任务命名、模型引导、调度或确认／执行逻辑。也没有扩大其他目录接口的请求参数。

## 工程验证

新增参数化行为回归覆盖 101 条关联的跨页读取：授权范围内的首尾设备获得正确关联，关联目录里的其他设备不能扩权；即使指定排序，上游仍返回重复时依旧拒收。测试全部使用虚构身份和设备。

- 修复前：新回归 2 项，正常读取分支报重复记录错误，坏页拒收分支通过。
