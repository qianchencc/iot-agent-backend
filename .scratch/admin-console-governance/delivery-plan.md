# 三项业务闭环交付切片

Status: approved-for-implementation（2026-11-04继续实施：白名单独立维护、不接业务，配置和审计范围不变；见[ADR0008](../../docs/adr/0008-standalone-phone-list.md)）。运行大屏、维护中心、导出、复杂授权、长期治理不属本轮。

每片必须贯通实际存储、Java接口、控制台页面和行为验证；不接受只写表单、只写数据库或模拟成功。

| 切片 | 真正阻塞项 | 可独立演示的交付 |
|---|---|---|
| 01 管理员登录与控制台壳 | 无 | 外置配置启动不依赖`.env`；独立管理员登录；Element Plus布局可访问白名单、配置、审计三页；未配置时安全失败 |
| 02 用户白名单闭环 | 01 | 管理员直接维护手机号与可选备注、持久保存和版本冲突处理；不接准入／认证／设备／任务业务，页面明确未接入 |
| 03 参数配置闭环 | 01 | 管理员读取、编辑、校验、保存实际可调参数；新运行真实采用新值，在途运行不被强制打断；秘密不回显；失败不伪报成功 |
| 04 用户操作审计闭环 | 01 | 按可信用户查看company/office操作，筛选时间、动作和结果；审计不依赖白名单，不展示秘密和隐藏思维 |
| 05 三项能力收口验证 | 02、03、04 | 真实浏览器完成登录→白名单→配置→审计主流程；完成加载、空、错误、冲突、窄屏、键盘和设计类skill检查 |

## 验收接缝

- 管理HTTP入口＋真实配置消费者＋隔离MySQL；浏览器验证管理员可见行为。
- 关键行为：未授权拒绝、配置真实生效、在途快照稳定、审计归属正确、重复事件不覆盖、秘密不回显。
- 真实设备、生产任务、通知和配置出口禁写；使用隔离协议夹具与独立数据库。

## 发布规则

以上切片已获用户批准，已发布到本目录 `issues/`。按编号从阻塞者开始实施；每个切片完成后运行聚焦检查，05完成后运行全套验证与设计复核。
