# ENERGY-COLD-01：能耗冷窗口复用

## 设计和实际范围

- 日统计、月度／同期／区域／夜间统计以及能耗报告，复用既有按身份、授权电表集合、自然月隔离的原始采样块；不是以日合计推算月统计。
- 按需读取窗口覆盖的月份，保留左锚点，并裁去报表结束时刻之后的采样。全授权集合用于月块身份，最终计算仍只输出选中表。
- 当前月沿用CURRENT刷新；并发上限仍为6。不增加新的调度器、队列、重试框架或缓存层。
- 共享流不可用时，原有best-effort报告仍按原逐表规则读取可用表，不把所有表一起变成无数据；401/403不降级。严格统计仍明确失败。
- 删除首读自动遍历24个月的准备器；历史由当前选中／可见范围按需准备。前端保留已有数据，初次及单日无结果时说明正在准备。
